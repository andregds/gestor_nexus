Configuração do Bot

O token fornecido pelo @BotFather.
ID do usuário, grupo ou canal.

📚 Como Configurar

1. Criar o Bot

  1. Abra o Telegram e pesquise por @BotFather.
  2. Envie o comando /newbot.
  3. Escolha um nome e um username para o bot.
  4. Copie o Token e cole no campo acima.

2. Descobrir o Chat ID

👤 Mensagem privada

Inicie conversa com o bot, pesquise @userinfobot e copie o ID retornado.

👥 Grupo ou canal

Adicione o bot ao grupo/canal e use um bot de identificação, como @RawDataBot, para obter o ID que começa com -100.

Configuração SMTP

Para Gmail, selecione Gmail no campo "Tipo de e-mail"; os dados SMTP serão preenchidos automaticamente.

Use senha de app quando o provedor exigir autenticação em duas etapas.

Uso nos lembretes

Depois de salvar, cadastre o e-mail do cliente na tela de Clientes e escolha o canal E-mail para os lembretes de cobrança.
