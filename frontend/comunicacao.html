Configuração do Bot

📚 Como Configurar

1. Criar o Bot

  1. Abra o Telegram e pesquise por @BotFather.
  2. Envie o comando /newbot.
  3. Escolha um nome e um username para o bot.
  4. Copie o Token e cole no campo acima.

2. Descobrir o Chat ID

👤 Mensagem privada

Inicie conversa com o bot, pesquise @userinfobot e copie o ID retornado.

👥 Grupo ou canal

Adicione o bot ao grupo/canal e use um bot de identificação, como @RawDataBot, para obter o ID que começa com -100.
