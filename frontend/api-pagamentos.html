Webhook Em local, a rota pública já existe no backend; em produção, use a URL do domínio real.
Configuração automática O sistema usa o endpoint /orders e escolhe a URL base correta conforme o ambiente selecionado.
Como configurar esta conta Cada usuário deve usar o próprio token PagBank. Para produção, selecione Produção, cole o token da conta PagBank que vai receber as cobranças e informe uma URL pública com HTTPS, por exemplo https://gestornexus.com.br/v1/webhooks/pagbank. Para testes, selecione Sandbox e use o token do ambiente de teste. O token de outra conta não serve para receber na conta atual.
Como configurar esta conta Cada usuário deve usar o próprio Access Token do Mercado Pago. O modo Sandbox abre o sandbox_init_point retornado pela preference; Produção usa o init_point. Configure também a URL pública do webhook em /v1/webhooks/mercadopago.
