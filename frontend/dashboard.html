Integração Telegram

Configure seu bot para receber alertas.

Configuração do Bot

O token fornecido pelo @BotFather.
ID do usuário, grupo ou canal.

📚 Como Configurar

1. Criar o Bot

  1. Abra o Telegram e pesquise por @BotFather.
  2. Envie o comando /newbot.
  3. Escolha um nome para o bot (ex: Meu Monitor).
  4. Escolha um username (deve terminar em 'bot', ex: meu_monitor_bot).
  5. O BotFather enviará o Token. Copie e cole no campo acima.

2. Descobrir o Chat ID

Dependendo de onde você quer receber os alertas:

👤 Para você (Mensagem Privada)

1. Inicie uma conversa com seu novo bot (clique em Começar/Start).
2. Pesquise por @userinfobot no Telegram.
3. Envie qualquer mensagem para ele.
4. Ele responderá com seu ID (ex: 123456789). Copie este número.

👥 Para um Grupo

1. Adicione o seu bot no grupo desejado.
2. Adicione também o bot @RawDataBot no grupo.
3. Assim que entrar, o RawDataBot enviará um JSON. Procure por "chat": { "id": -100... }.
4. Copie esse ID (incluindo o sinal de menos).
5. Remova o RawDataBot do grupo depois.

📢 Para um Canal

1. Adicione o bot como Administrador do canal.
2. Encaminhe uma mensagem qualquer desse canal para o bot @getidsbot.
3. Ele retornará o ID do canal (começa com -100).
